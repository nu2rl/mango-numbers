# Git Auto-Commit and Push Rule

Always create a Git commit and push to GitHub (`git push origin main`) after completing any code modifications, bug fixes, or feature additions in this project.

## Guidelines:
1. **Commit Message**: Use a clear, descriptive commit message detailing what changes were made (e.g., `feat: updated login UI`, `fix: resolved auth handler bug`).
2. **Push**: Automatically push the commit to the `main` branch on GitHub (`https://github.com/nu2rl/mango-numbers`).
3. **Safety**: Ensure `.env` and other secret files remain untracked.
