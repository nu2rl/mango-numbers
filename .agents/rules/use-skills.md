# Project Skills Usage Guidelines

Always actively reference and apply the installed project skills (`.agents/skills/`) when designing, building, or refining the application:

1. **`anti-ui-slop`** (`.agents/skills/anti-ui-slop/SKILL.md`): Avoid generic AI-looking UI. Ensure intentional visual hierarchy, distinct brand design, complete interaction states, and premium finish.
2. **`ui-design`** (`.agents/skills/ui-design/SKILL.md`): Craft intentional, high-conversion web interfaces with clear spatial harmony, contrast, and micro-interactions.
3. **`web-design-guidelines`** (`.agents/skills/web-design-guidelines/SKILL.md`): Audit and enforce accessibility, semantic HTML, responsive standards, and UX best practices.
4. **`tailwind-4-docs`** (`.agents/skills/tailwind-4-docs/SKILL.md`): Reference official Tailwind v4 conventions, utility choices, and gotchas whenever styling components.
5. **`ponytail`** (`.agents/skills/ponytail/SKILL.md`): Focus on minimal diffs, standard libraries, and avoiding over-engineering.
