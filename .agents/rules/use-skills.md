# Installed Skills Guidelines

Always actively reference and apply the installed project skills (`.agents/skills/`) when designing, building, or refining the application:

1. **`anti-ui-slop`**: Avoid generic AI-looking UI. Ensure intentional visual hierarchy, distinct brand design, complete interaction states, and premium polish.
2. **`ui-design`**: Craft intentional, high-conversion web interfaces with clear spatial harmony, contrast, and micro-interactions.
3. **`web-design-guidelines`**: Audit and enforce accessibility, semantic HTML, responsive standards, and UX best practices.
4. **`tailwind-4-docs`**: Reference official Tailwind v4 conventions, utility choices, and gotchas whenever styling components.
